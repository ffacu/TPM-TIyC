COMPACTACION DE ARCHIVOS

Realizar un programa de manera que dado un archivo de tipo texto  (txt, …),  de la posibilidad de:

-  Compactar el archivo utilizando el método de Huffman.
(usando una tabla de frecuencias por archivo, o sea las frecuencias específicas del archivo mismo).

Tomaremos un archivo y aplicaremos Huffman para compactarlo y luego de realizar los procesos
que necesitemos, descompactaremos el archivo que estemos usando obteniendo el archivo original.

Realizar una pantalla que se pueda visualizar texto original y texto recuperado en pantalla.

-----------------------------------------------------------------------------------------------------------------------

Entonces el programa deberá tener un MENU DE OPCIONES que  permita:

-CARGAR ARCHIVO TEXTO

-COMPACTAR ARCHIVO (.TXT, .DOC, .WP,….)    GENERANDO   “.huf”

-DESCOMPACTAR ARCHIVO (.huf )                        GENERANDO  “.dhu” (descompactado)

-VER ARCHIVOS EN PANTALLA
(QUE MUESTRE 2 ARCHIVOS   original y obtenido , Y SE PUEDA HACER SCROLLING DE LOS MISMOS)

-VER ESTADISTICA
(Haga una muestra  ESTADISTICA  de como se ajustan los tamaños de los archivos,  ORIGINAL,
COMPACTADO Y DESCOMPACTADO).
